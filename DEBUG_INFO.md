# Отладочная информация и логи

## Где посмотреть логи в N8N

### 1. В интерфейсе N8N

1. **Выполнение Workflow:**
   - Откройте workflow в N8N
   - Нажмите на узел, который хотите проверить
   - В правой панели нажмите вкладку **"Execution"** или **"Output"**
   - Вы увидите вывод `console.log()` и `console.error()` из узлов Code

2. **История выполнений:**
   - В главном меню выберите **"Executions"**
   - Найдите нужное выполнение workflow
   - Кликните на него, чтобы увидеть детали
   - Кликните на любой узел, чтобы увидеть его ввод/вывод

3. **В узле Execute Command:**
   - Откройте узел "Update Excel Script"
   - Во вкладке "Output" вы увидите:
     - `stdout` - стандартный вывод скрипта
     - `stderr` - стандартный вывод ошибок (сюда идут все `console.error()`)

### 2. В файле Excel

После выполнения workflow в файле Excel будет создан лист **"DEBUG"** с отладочной информацией:
- Дата обновления
- Всего строк в файле
- Всего обновлений
- Обновлено строк
- Не найдено тикетов
- Список всех обновлений с тикетами и значениями

### 3. В консоли браузера

Откройте консоль разработчика (F12) в браузере, где открыт N8N, и посмотрите логи там.

## Отладочная информация в скрипте

Скрипт `update-excel.js` выводит отладочную информацию в `stderr`:
- `DEBUG: Script started` - скрипт начал работу
- `DEBUG: inputFile` - путь к входному файлу
- `DEBUG: outputFile` - путь к выходному файлу
- `DEBUG: updatesData length` - длина данных для обновления
- `DEBUG: Base64 decoded successfully` - успешно декодирован base64
- `DEBUG: JSON parsed successfully` - успешно распарсен JSON
- `DEBUG: Starting row updates` - начато обновление строк
- `DEBUG: Updated row X` - обновлена строка X
- `DEBUG: Update complete` - обновление завершено

## Узлы с отладочной информацией

1. **Update Excel File** - выводит информацию о подготовке данных
2. **Debug Before Script** - выводит информацию перед запуском скрипта
3. **Update Excel Script** - выполняет скрипт и выводит stdout/stderr
4. **Parse Update Result** - парсит результат и выводит отладочную информацию

## Проблема с зависанием

Если узел "Update Excel Script" зависает:

1. Проверьте в узле "Debug Before Script" длину base64 строки
2. Проверьте в узле "Update Excel Script" вывод stderr - там должны быть логи скрипта
3. Если скрипт не запускается, проверьте:
   - Правильность пути к файлу
   - Наличие файла `update-excel.js` в папке проекта
   - Права доступа к файлам

## Как проверить работу

1. Запустите workflow
2. Проверьте вывод узла "Debug Before Script" - должен показать длину base64
3. Проверьте вывод узла "Update Excel Script" в stderr - должны быть логи скрипта
4. Проверьте вывод узла "Parse Update Result" - должен показать результат выполнения
5. Откройте Excel файл и проверьте лист "DEBUG" с отладочной информацией
