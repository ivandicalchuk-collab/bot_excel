# Бот для расчета времени в Excel через PlanetCalc

Этот бот автоматизирует расчет разницы времени между датами, используя калькулятор с сайта planetcalc.ru/4309/, и записывает результаты обратно в Excel файл.

## Требования

1. **N8N** - установленный локально
2. **Node.js** - версия 14 или выше
3. **Puppeteer** - для автоматизации браузера

## Установка

### 1. Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm init -y
npm install puppeteer
```

### 2. Настройка N8N

1. Запустите N8N локально
2. Откройте веб-интерфейс N8N (обычно http://localhost:5678)
3. Импортируйте workflow:
   - Нажмите на меню (три точки в правом верхнем углу)
   - Выберите "Import from File"
   - Выберите файл:
     - **n8n_workflow_simple.json** (рекомендуется для начала, не требует Puppeteer)
     - **n8n_workflow_puppeteer.json** (если нужен сайт planetcalc.ru)

### 3. Настройка путей в workflow

После импорта workflow, вам может потребоваться настроить пути к файлам:

1. В узле **Read Excel File** проверьте путь к файлу:
   ```
   C:\Users\ASUS\Desktop\bot_excel\calceulated_algoritm_tg_billing.xlsx
   ```
   Если ваш файл находится в другом месте, измените путь.

2. В узле **Update Excel File** проверьте тот же путь

3. **Только для n8n_workflow_puppeteer.json**: В узлах **Calculate First Time (Puppeteer)** и **Calculate Second Time (Puppeteer)** проверьте путь в параметре `cwd`:
   ```
   C:\Users\ASUS\Desktop\bot_excel
   ```
   Также убедитесь, что в узлах **Prepare First Calculation** и **Prepare Second Calculation** путь `projectPath` указан правильно.

## Структура Excel файла

Файл должен содержать следующие столбцы на листе "лист 1":

- **№ Тикета** - номер тикета (используется для определения строк)
- **Дата передачи** - дата передачи
- **Время передачи** - время передачи
- **Дата возврата** - дата возврата
- **Время возврата** - время возврата
- **Дата взятия тикета в работу сотрудником ЦКП** - дата взятия в работу
- **Время взятия тикета в работу сотрудником ЦКП** - время взятия в работу
- **Время обработки** - столбец для результата первого расчета (будет заполнен автоматически)
- **Время с момента передачи тикета до взятия его обратно в работу сотрудниками ЦКП** - столбец для результата второго расчета (будет заполнен автоматически)

## Как работает бот

1. **Чтение Excel** - Бот читает данные из файла, начиная со 2-й строки (первая строка - заголовки)

2. **Фильтрация** - Отбираются только строки, где есть номер тикета

3. **Обработка по одной строке** - Каждая строка обрабатывается отдельно

4. **Два расчета**:
   - **Первый расчет**: Разница между "Дата передачи + Время передачи" и "Дата возврата + Время возврата"
     - Результат записывается в столбец "Время обработки"
   
   - **Второй расчет**: Разница между "Дата передачи + Время передачи" и "Дата взятия тикета + Время взятия тикета"
     - Результат записывается в столбец "Время с момента передачи тикета до взятия его обратно в работу сотрудниками ЦКП"

5. **Использование сайта** - Для каждого расчета бот:
   - Открывает сайт https://planetcalc.ru/4309/
   - Вводит даты и времена в поля калькулятора
   - Получает результат
   - Если сайт недоступен, вычисляет разницу самостоятельно

6. **Запись результатов** - Результаты записываются обратно в Excel файл

7. **Повторение** - Процесс повторяется для всех строк с тикетами

## Запуск

1. Убедитесь, что Excel файл закрыт
2. В N8N нажмите кнопку "Execute Workflow" (или используйте триггер, если настроен)
3. Дождитесь завершения выполнения
4. Проверьте результаты в Excel файле

## Альтернативные варианты workflow

В проекте есть несколько вариантов workflow:

- **n8n_workflow_puppeteer.json** - вариант с использованием Puppeteer для реального взаимодействия с сайтом planetcalc.ru (требует установки Puppeteer)
- **n8n_workflow_simple.json** - упрощенный вариант с прямым расчетом времени (НЕ требует Puppeteer, работает быстрее, рекомендуется для начала)

### Какой вариант выбрать?

- **n8n_workflow_simple.json** - если вам не обязательно использовать именно сайт planetcalc.ru, и вы хотите быстро начать работу
- **n8n_workflow_puppeteer.json** - если вам обязательно нужно использовать сайт planetcalc.ru для расчетов

## Устранение неполадок

### Ошибка "Puppeteer not found"
Убедитесь, что Puppeteer установлен:
```bash
npm install puppeteer
```

### Ошибка "Cannot find module"
Проверьте, что все файлы находятся в правильной папке и пути в workflow настроены корректно.

### Ошибка при чтении Excel
- Убедитесь, что файл закрыт
- Проверьте правильность пути к файлу
- Убедитесь, что лист называется "лист 1" (с маленькой буквы)

### Ошибка при работе с сайтом
Если сайт planetcalc.ru недоступен, бот автоматически вычислит разницу времени самостоятельно.

## Формат даты и времени

Убедитесь, что в Excel файле даты и времена имеют правильный формат:
- **Дата**: ГГГГ-ММ-ДД или ДД.ММ.ГГГГ
- **Время**: ЧЧ:ММ или ЧЧ:ММ:СС

## Примечания

- Бот обрабатывает строки последовательно, что может занять время при большом количестве данных
- Рекомендуется сделать резервную копию Excel файла перед запуском
- При первом запуске Puppeteer может загрузить браузер Chromium (это нормально)
