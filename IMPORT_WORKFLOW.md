# Инструкция по импорту workflow в N8N

N8N должен быть запущен и доступен по адресу: **http://localhost:5678**

## Шаги для импорта workflow:

1. **Откройте N8N в браузере**
   - Если браузер не открылся автоматически, перейдите на: http://localhost:5678

2. **Импортируйте workflow:**
   - Нажмите на меню (три точки в правом верхнем углу) или кнопку "Workflows"
   - Выберите **"Import from File"** или нажмите кнопку **"+"** и выберите **"Import from File**
   - Выберите файл: **`n8n_workflow_simple.json`**
   - Нажмите "Import"

3. **Настройте пути к Excel файлу:**
   
   После импорта откройте workflow и проверьте следующие узлы:
   
   **Узел "Read Excel File":**
   - Откройте узел двойным кликом
   - Проверьте путь к файлу: `C:\Users\ASUS\Desktop\bot_excel\calceulated_algoritm_tg_billing.xlsx`
   - Если файл находится в другом месте, измените путь
   - Нажмите "Save"
   
   **Узел "Update Excel File":**
   - Откройте узел двойным кликом
   - Проверьте тот же путь к файлу
   - Нажмите "Save"

4. **Проверьте структуру Excel файла:**
   
   Убедитесь, что в Excel файле есть следующие столбцы на листе "лист 1":
   - № Тикета
   - Дата передачи
   - Время передачи
   - Дата возврата
   - Время возврата
   - Дата взятия тикета в работу сотрудником ЦКП
   - Время взятия тикета в работу сотрудником ЦКП
   - Время обработки (будет заполнено автоматически)
   - Время с момента передачи тикета до взятия его обратно в работу сотрудниками ЦКП (будет заполнено автоматически)

5. **Запустите workflow:**
   - Убедитесь, что Excel файл **закрыт**
   - В N8N нажмите кнопку **"Execute Workflow"** (кнопка Play в правом верхнем углу)
   - Или используйте кнопку **"Test workflow"** для тестирования
   - Дождитесь завершения выполнения
   - Проверьте результаты в Excel файле

## Альтернативный способ импорта:

Если у вас есть доступ к файловой системе N8N, вы можете скопировать workflow файл в папку workflows N8N:
- Windows: `C:\Users\<username>\.n8n\workflows\`
- Затем перезапустите N8N

## Устранение проблем:

### N8N не открывается
- Проверьте, что N8N запущен (должно быть окно PowerShell с логами N8N)
- Попробуйте открыть вручную: http://localhost:5678
- Проверьте, что порт 5678 не занят другим приложением

### Ошибка при импорте
- Убедитесь, что файл `n8n_workflow_simple.json` находится в папке проекта
- Проверьте, что файл не поврежден

### Ошибка при чтении Excel
- Убедитесь, что Excel файл закрыт
- Проверьте правильность пути к файлу
- Убедитесь, что лист называется "лист 1" (с маленькой буквы)
