## Следующие шаги:

### 1. Импорт workflow в N8N

В открытом браузере с N8N:

1. Нажмите на меню (три точки) или кнопку **"Workflows"**
2. Выберите **"Import from File"**
3. Выберите файл: **`n8n_workflow_simple.json`** из папки проекта
4. Нажмите **"Import"**

### 2. Настройка путей

После импорта workflow:

1. Откройте узел **"Read Excel File"** (двойной клик)
2. Проверьте путь: `C:\Users\ASUS\Desktop\bot_excel\calceulated_algoritm_tg_billing.xlsx`
3. Если файл в другом месте - измените путь
4. Нажмите **"Save"**
5. То же самое для узла **"Update Excel File"**

### 3. Запуск workflow

1. **Закройте Excel файл** (если открыт)
2. В N8N нажмите кнопку **"Execute Workflow"** (▶️ Play)
3. Дождитесь завершения
4. Проверьте результаты в Excel файле

## Файлы проекта:

- **n8n_workflow_simple.json** - простой workflow (рекомендуется)
- **n8n_workflow_puppeteer.json** - workflow с Puppeteer (для работы с сайтом)
- **puppeteer-calculator.js** - скрипт для Puppeteer
- **README.md** - полная документация
- **QUICKSTART.md** - быстрый старт
- **SETUP.md** - инструкция по установке
- **IMPORT_WORKFLOW.md** - детальная инструкция по импорту

## Важно:

- N8N работает в отдельном окне PowerShell - **не закрывайте его**
- Для остановки N8N нажмите **Ctrl+C** в окне PowerShell
- Excel файл должен быть **закрыт** перед запуском workflow

## Если что-то пошло не так:

1. Проверьте, что N8N запущен (окно PowerShell должно быть открыто)
2. Откройте http://localhost:5678 вручную
3. Смотрите инструкции в файле **IMPORT_WORKFLOW.md**
